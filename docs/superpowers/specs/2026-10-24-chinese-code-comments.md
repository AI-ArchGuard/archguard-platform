# 学习型中文代码注释约定

状态：所有者已在聊天中批准范围和顺序；本文记录该批准，不新增功能或运行授权。

## 目的

让项目所有者直接阅读代码时，能理解模块职责、类和方法的用途、关键调用关系及设计原因。注释描述当前实现，不把历史设计或未来计划写成已经具备的能力。

## 注释方式

- 模块、类和公开接口：交代职责、所属层次及上下游，优先解释业务含义。
- 主要方法：说明前置条件、输入输出、权限及副作用；简单取值和赋值不逐行重复。
- 关键分支：说明授权隐藏、事务/锁、并发、审计、异常及失败关闭等处理的原因。
- 测试：说明场景、保护的不变量与预期行为；不改断言、测试数据或工具指令。
- 保留准确的已有说明及必要技术术语，中文解释与代码标识符对应。

## 不可改变的边界

- 只修改注释及配套阅读说明，不修改可执行语法、标识符、字符串、接口、配置值、测试断言、依赖或 CI。
- 已发布的16个 SQL 迁移、生成文件、契约、报告/来源 fixture 和固定向量保持原字节；通过相邻说明解释。
- 不在 Java 文本块、SQL/JSON 字符串或模板字符串内添加所谓注释。
- 不改许可证、生成器/类型检查等有工具语义的注释，不提交本地配置、凭据或缓存。
- 保留用户现有修改，在独立工作树中以核实的 main 为起点；本任务不部署、不修复 Docker、不调用模型、不改变阶段状态。

## 分批顺序

Platform 主要业务流程 → Scanner → Web → Deploy → Samples/其他工具脚本。Platform 内从 Project 开始，再逐模块处理。Gateway/Evals 尚无业务实现，不为增加注释创建功能占位代码。

第一批是 Project 模块的43个生产 Java 文件及2个 Project 测试文件；增加中文阅读指南和 README 入口。其他模块及仓库不在第一批范围内，不以第一批冒充全项目覆盖。

第二批接续 Repository 的13个生产文件、RuleSet 的15个生产文件和1个路径测试，累计74个 Java 文件。增加对应阅读指南；第一批保持不动，其他模块/仓库继续列为待办。

第三批接续 ScanJob 的20个生产文件、Finding 的21个生产文件及1个报告消费测试，累计116个 Java 文件。阅读指南解释异步扫描、结果接受与人工处置的联系及现有一致性限制；前两批代码保持不动。

第四批接续 Governance 的82个生产文件、4个内部单元测试及2个 API 集成测试，累计204个 Java 文件。阅读指南区分不可变基线、分类、门禁、例外、报告接收、Webhook 与 PR 修订差异；前三批保持不动，其余契约/迁移测试及其他模块继续列为待办。

## 验证和交付

使用 JDK 自带编译器解析修改前后的 Java 语法树，证明可执行结构不变；保留全部未触及资源。先执行对应批次的相关测试，再执行仓库完整 `mvnw verify`、空白及差异检查。执行结果和跳过项如实记录。每批一次独立评审核对注释是否准确、易懂以及是否越过只改注释的边界。

本轮只交付本地可审阅修改；不自动推送、创建/合并 PR、发布或改分支保护。

# Agent 4F — Web 引用和摘要的只读契约补充

4F Web 需要可验证的 PR 修订 ID 与文档版本读取入口。本补充复用治理和文档模块公开应用接口，不增加迁移、依赖、模型出口或业务写入。

- PR 列表与单项读取增加可选 `currentHeadRevisionId`。仅从与当前 head 的 Project、Repository、PR、分支、事件时间和最后一次已应用 delivery 全部匹配的 V7 历史返回 ID。缺少可信历史时为 null/省略；不得把未应用或过期 webhook 推断为当前修订。原 Viewer 授权仍适用。Agent 创建时继续检查完成报告与修订绑定，避免读取后 head 变化造成错误摘要。
- `GET /api/v1/projects/{projectId}/documents/versions/{versionId}` 返回确切不可变版本，复用 `DocumentOperations.getVersionById`，每次重新检查当前 Viewer 权限。未知版本、跨 Project 或授权撤销均返回隐藏式 404。历史引用不需要枚举文档或跟随最新版本。

现有 v1 契约为增量兼容扩展，Agent/Scanner Schema 版本不变。先合并 Platform 并核对 main CI，再同步 Web 固定快照并部署 Web。Web 将摘要绑定已选择的 Finding、已完成扫描、报告摘要与该 PR 修订；引用核对版本 ID、内容 SHA 与请求版本集合。失败与无可信历史均明确显示不可用。

回滚先隐藏 Web Agent 入口，再回退应用；保留 V7–V10 与全部历史文档/解释。原 Finding、PASS/FAIL 和 CI 退出码不参与此补充。

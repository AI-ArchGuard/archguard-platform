# Agent v0.5.0 — 4G 合成安全与恢复加固

范围：Docs Feature Spec、ADR-0010/0011 的默认关闭/确定性假模型路径。真实 DeepSeek 网络、账户条款、价格目录与 Secret 审批仍由独立 Issue #43 处理；本切片不批准或实现真实外发，不开启 Gateway/正式 Evals，不创建阶段报告。

## 恢复与并发

进程在创建后分派前或提供方调用中断时，持久化请求可能遗留。启动在 Agent 独立迁移成功后检查，之后每 15 秒有界检查最多 100 条记录。排队创建时间或运行更新时间超过 60 秒的请求按数据库条件更新为失败：排队为 `MODEL_TIMEOUT`，运行中为未知结果 `INTERNAL_ERROR`。60 秒覆盖既有 30 秒提供方硬上限及结算宽限；不重新派发，不自动调用提供方。运行中未知成本的当日预留不释放，历史终态不改写。

选择记录后更新仍复核状态和时间，刚认领的正常任务不会被过期快照误终止；多实例或重复启动只成功更新、审计一次。恢复使用专属调度线程，确定性调度保留 Spring 原配置，避免 Agent 恢复占用扫描调度线程。恢复不依赖身份上下文，不读取其他领域表，仅写 Agent 请求与公开审计接口；失败只影响 Agent。数据库不可用时记录安全错误类型并留待下一次检查，不传播到 Scanner/门禁启动路径。没有迁移变更。

Project/部署 UTC 日额度继续在同一事务按固定顺序加锁。八个并发预留、单次边界、非法结算、重新创建 store 后的账本读取与 UTC 日切换均以真实 PostgreSQL 验证。未知收费保守占用额度，不以失败释放可能已计费的预留。

## 不可信用量与展示

提供方 Token 计数须在 8,000/1,500 上限内，延迟非负；响应 ID/模型 ID 仅接受 1–128 个受限 ASCII 标识字符，不接受换行、正文或任意 URL。合成实际费用若超过调用前预留，必须失败并保留未知收费，不能静默截成预留金额。异常元数据不进入 Web 或审计。此合成计价验证不是 DeepSeek 真实结算或 Token 估算验证。

模型输入测试核对只选中 Finding/Evidence 和指定文档版本：没有内部 ID、未选文档、跨 Project、绝对路径、报告或凭据字段。注入指令仅保留在有界数据摘录中，Prompt/Schema/引用集合不因正文改变；模型端口无工具或外联控制字段。调用中撤权拒绝保存成功结果，当前读取隐藏原结果。审计核对 traceId、摘要、版本、Token、两种延迟及预估/实际费用；没有 Prompt、文档正文或原始输出。

Web 状态轮询前一次未结束时不发起第二次，避免慢响应回退状态；断网只恢复查询，不自动重发 POST。重复显式提交在进行中被阻止，未知提交重用原幂等键。终态继续按当前权限查询，401/403/404 后清除建议。组件覆盖全部稳定失败码，浏览器以合成 API 验证超时/额度失败前后的 `PASS/0`、`FAIL/2` 与原始文本不展示。

## 验证与案例

最小检查：`AgentExplanationIntegrationTest`、`AgentBudgetIntegrationTest`、`AgentRecoveryIntegrationTest`，Web hook/组件与浏览器测试；再执行 Maven `verify`、Web 全检查/API 生成/浏览器、Samples 全固定样例检查。Samples `agent/hardening-cases-v1.json` 保存 14 个未来可复用案例及精确测试指针，清单脚本仅验证定义，不冒充运行验收或正式 Evals。

缺陷先由失败测试复现：遗留请求未结束、慢轮询重叠、异常提供方元数据/用量被接受或费用静默截断。补丁后的测试和 PR/main CI 才是完成证据；本设计本身不宣称未执行的网络、真实模型或 Compose 验证通过。

兼容顺序：Docs 已冻结 → Samples 案例 → Platform 4G → Web 4G → Deploy 4H。Agent 与 Scanner Schema 均保留 `0.1.0`，Scanner `v0.2.1` 不改。回滚先关闭 Web 入口与模型，再回退应用；保留 V1–V10、不可变文档、请求历史、额度和审计，不修改旧迁移。4G 相关 PR 合并且各 main CI 成功后才启动 4H；真实模型发布关卡不随合成测试关闭。

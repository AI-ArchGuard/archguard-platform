# 4H 本地合成适配器

状态：仅供独立本地 Compose 验收，不是 DeepSeek 或真实模型发布。沿用 ADR-0010/0011、4B 契约及 4G 校验；不改变公共接口、依赖、主迁移 V1–V8 或 Agent V9/V10。

打包制品的默认端口仍禁用。仅当 `local-compose` 与 `agent-synthetic` 两个 profile 同时存在，且 `ARCHGUARD_AGENT_SYNTHETIC_ENABLED=true` 时装配无网络的确定性适配器；调用还必须显式设置 `ARCHGUARD_AGENT_ENABLED=true`。真实适配器没有实现、凭据或 HTTP 客户端，#43 外发关卡不变。

适配器只复制当前获授权输入中的不透明 Finding/引用句柄，所有说明和建议均为固定的“合成验收”文本，不回显文档指令、Evidence 正文或名称。响应继续经过现有 Schema、三次授权、引用、费用与业务校验。固定 100/80 Token、260 µUSD 只是合成账本数据，不能作为真实 Token、价格、账单或模型质量证据。

部署人员可以固定 `ARCHGUARD_AGENT_SYNTHETIC_SCENARIO` 为 `SUPPORTED`、`OUTPUT_INVALID`、`CITATION_INVALID`、`TIMEOUT` 或 `UNAVAILABLE`。API 用户无法选择场景；未知场景拒绝启动。超时场景可中断等待，现有 worker 的硬超时与无重试策略不变。所有场景不含外联、工具或源码修改。

验收先核对装配开关和固定输出，再执行完整 `verify`、架构与迁移检查。Deploy 先引用已合并且主分支 CI 成功的 Platform 提交，再做真实 Web/Platform/PostgreSQL Compose 合成验收。回滚移除合成 override 或关闭 Agent 开关，保留文档、解释、预算和审计；正式真实模型发布仍暂停。

# Agent v0.5 — 有界、可中断的凭据消费等待

范围：修复真实执行核心到加密凭据槽位之间的等待边界。承接 ADR-0012/0013，不改变 Token、价格、批准、外发协议或数据处理语义。Platform 仍为 0.4.0；没有新依赖、迁移、公开 API、Web、运行配置或部署变更。真实核心与桥接仍未装配，公开构造器继续拒绝外发。

## 同一槽位、同一期限

凭据状态、写入、删除、旧消费和有界消费共用同一个 `ReentrantLock`，不为真实路径另建锁域。服务的缓存初始化使用 `AtomicReference` CAS；构造不读取凭据/主密钥文件，只有胜者实例会被返回。替换/删除与消费的原串行顺序、密文格式、当前版本校验和无旧 Key 回退保持不变。不支持多个进程共享槽位。

旧内部消费改用 `lockInterruptibly`，不新增任意期限。有界消费使用 `tryLock(remainingNanos)`：过期或被中断的等待者在占用者释放前退出，且不会在稍后取锁后执行迟到回调；中断标志保留。状态、写入和删除仍是串行管理操作，不据此承诺有界退出。

`CredentialUseSource` 和核心的 `CredentialUse` 保留原 SAM，并增加接收原单调时钟剩余纳秒的重载。默认实现直接失败，不允许回退旧无界消费。核心只调用有界重载；缺少实现会失败关闭，不读取 Key 或发送。

同一执行起点产生的剩余预算依次经过核心、桥接、凭据服务与存储，不能每层重置 30 秒。服务在意图审计前后检查，存储在取锁后、读主密钥后、解密后、最终回调前后检查。凭据层同时从首次读取供应商之前开始计本地实际耗时，限制为初始剩余值；即使供应商错误地返回常量也不能续期。预算为零、负值、大于 30 秒、供应商抛错或线程已中断均安全失败。

供应商是可信时钟回调，只能读取剩余时间/中断状态，不能查询身份、审计、数据库或其他领域模块。同线程重入在调用供应商之前拒绝；服务还在 actor/audit 之前拒绝。锁外 preflight 与意图审计不变；锁内只保留存储读取、期限检查和最终同步发送，不引入设置行锁或费用审计反向锁序。

## 失败、清理和已知费用

锁、重入作用域与可擦除主密钥/明文 byte[] 在 finally 清理；错误仍无 cause、路径或 Key 正文。凭据 HTTP 错误类别不变；桥接把原期限耗尽或中断映射为 `MODEL_TIMEOUT`，其他存储不可用继续失败关闭，不自动重试。

桥接与核心在最终发送返回时先捕获真实回复，再处理来源清理错误、重复回调或到期。后续失败清空业务输出，但不能丢弃合法 usage 和安全追溯字段；实际费用仍由原独立事务先结算，迟到结果不能成为成功解释。不使用 Future 超时丢弃已经产生的费用证据。

## 验证与未完成关卡

先用回归测试实际复现旧 monitor 等待无法中断，以及核心误调用无界消费，再修复生产代码。临时假 Key/主密钥、实际线程与 latch 验证等待超时/中断在持有者释放前退出、无迟到回调、同一缓存锁域、期限经过意图审计后不续期、重入拒绝、旧接口默认拒绝、回复后失败保留已知费用。继续运行原凭据、核心、桥接、账本、恢复和架构回归；全部验证仅用合成数据，不读运行时 Key、不调用模型或账户 API。

完整回归曾发现领取测试的历史固定时间与缓存 Spring 上下文中的真实恢复时钟竞争：后台可能合法终结夹具后再检查 QUEUED。该测试改为每个用例取微秒精度的当前时间快照，仍在用例内固定；不关闭恢复任务、不修改生产恢复逻辑，也不降低 QUEUED/领取与历史保留断言。

**不是完整的 30 秒端到端硬取消证明。** 同步文件/ACL/加密操作、身份/领域 API、审计、JDBC 连接/行锁/语句与提交仍可能等待；本切片只能在这些操作返回后拒绝迟到消费或成功。不能以凭据锁修复替代生产连接、语句、取消回收、调度、网络准入与恢复验收。

## 当前交付与仍关闭的运行入口

- `DeepSeekHttpTransport` 固定 `https://api.deepseek.com/responses`，只构造单次 POST；无 URL/模型/代理配置，凭据仅进入 Authorization，不生成正文/异常日志。它不是 Spring Bean 或 AgentModelPort，当前 worker 不装配它，原来的 syntheticOnly 拦截不变。
- `BoundedJdkHttpExchange` 使用 Java 21 自带 HTTPS 和默认信任库、显式 HTTPS 主机校验、HTTP/1.1、Redirect.NEVER、显式 NO_PROXY。单次最多 30 秒，连接最多 5 秒；外层等待覆盖响应正文，取消 CompletableFuture 和 BodySubscriber。正文缓冲最多 64 KiB；非 200 在订阅阶段取消，不读取/展示错误正文。调用者必须关闭 client；测试验证 client 实际终止，不只检查 future 状态。
- `DeepSeekRuntimeSecret` 只读取调用者指定的受控绝对路径、小型常规文件，拒绝符号链接/解析路径变化、空值/非法字符/头注入。没有环境默认值、Web 输入、业务存储或运行配置；本切片未配置或读取真实 Key。读出的字节缓冲清零；JDK Authorization 必须短暂使用 String，不能宣称完全清除堆中的凭据。
- `DeepSeekPriceSnapshot` 复用 2026-10-06 官方查询快照：高峰输入缓存未命中/命中、输出 USD 0.30/0.006/1.20 每百万 Token。最坏 8,000/1,500 预留 4,200 microUSD，按实际缓存命中一次向上舍入。这只是计算器，不是批准、账单、已落库预留/结算或开启权限。

## JDK 初始化关卡

[Java 21 网络属性](https://docs.oracle.com/en/java/javase/21/core/java-networking.html)明确：连接失败可能自动重试，非幂等方法重试由另一属性控制，HTTP 日志可包含 headers/content，测试属性可关闭主机校验。未来运行出口必须在 JVM 启动时配置：

```text
-Djdk.httpclient.disableRetryConnect=true
-Djdk.httpclient.enableAllMethodRetry=false
-Djdk.internal.httpclient.disableHostnameVerification=false
```

不得打开 `jdk.httpclient.HttpClient.log`。代码检查不符合设置时失败关闭，不在调用前临时修改全局属性；初始化后修改系统属性不证明 JDK 已使用新设置，未来启用检查还须核对实际启动参数并重启验证。Maven Surefire 仅为测试子 JVM 设置安全启动参数，不能替代 Deploy 的运行配置。

## 假 HTTP 与隔离

生产目标没有 override；测试在独立 Exchange seam 把已断言的官方 request 重建为 `127.0.0.1` 临时端口，由本地 JDK HttpServer 提供固定响应。这个重写只存在测试源码，不提供生产 HTTP/loopback 开关。

覆盖固定目标/字段、坏凭据及上限前零交换、302/401/429/500/503 仅一次、不跟随重定向、连接中断不重试、chunked 超大正文中止、正文停顿超时及 client 终止、非 JSON/原始异常脱敏、拒绝继承代理和不安全 JVM 属性、Secret 大小/路径/头注入，以及价格边界/缓存/舍入/过期版本。

本切片没有生产调用授权策略，不把“坏参数零交换”冒充部署/Project 授权测试。现有 AgentUnapprovedAdapterIntegrationTest 必须继续通过；没有接入端口，因此打开现有 Agent 开关仍不可调用真实服务。

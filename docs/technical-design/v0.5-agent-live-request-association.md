# 真实请求关联与创建基础

状态：实现基础；没有真实 HTTP 创建入口、调度器或外发装配。

依据 ADR-0012、ADR-0013、个人启用记录、合成批次和真实执行核心设计。本切片不改变官方 Responses 协议、固定模型、外发数据、公共 Request View/OpenAPI 或 Scanner Schema，也不构成真实调用或费用批准。

## 持久化边界

独立 Agent V14 追加 `agent.live_request_links`，绑定新请求、Project、批准批次、模板、启用记录、凭据版本、Project 设置 revision 和创建时间。关联按请求唯一，不允许 UPDATE/DELETE；请求、模板、批次和启用记录使用同 Project 复合外键，拒绝自身模板及负 revision。没有 Key、密码、主密钥、输入正文或客户数据字段。

不回填旧历史，不把旧模板、attempt 或结果改写为真实请求。V9–V13 保持不变。旧无关联 attempt 仍可读取、幂等返回和独立结算已发生费用，但不能再次通过发送检查。

## 内部创建事务

`LiveRequestOperations.create` 是内部应用契约，无 Controller、HTTP 参数、执行器或 afterCommit 模型回调。按 owner + Project Maintainer + 原有 Origin/TLS 检查准入，先锁 Project 设置，再锁批次 usage。检查默认部署开关、Project 设置、批准/价格有效期、当前凭据元数据版本、固定模型/协议、批准合成来源证明及模板归属。

只复制已批准的终态 synthetic 模板；保留选择、最小 Evidence 投影、文档版本和引用候选，仅换为固定 live Prompt/model/profile/catalog 和服务器生成的 digest。新请求获得独立 ID、当前可信 requester 和 traceId，状态为 QUEUED。使用 `LiveResourceAuthorizer` 经公开领域 API 精确核验当前授权、已完成扫描/PR 修订、Finding/Evidence 和文档版本/片段；提交前再次复核期限、来源和凭据元数据。

请求、关联和脱敏创建审计在同一 REQUIRES_NEW 事务中提交。任何插入或审计失败全部回滚；拒绝审计独立记录稳定操作名与原因类别，不保存正文或凭据。创建不领取请求、不预留费用、不消费 Key，也不访问模型或账户。

幂等范围仍为 Project/requester/key：相同 batch/template/digest/profile/关联返回原记录，不重新创建、重新审计或调度；不同模式或批次/模板冲突。重放只返回历史，不恢复撤销/过期授权；后续执行必须重新检查。

## 执行隔离

真实费用预留和发送检查必须验证持久化关联与参数、设置 revision、启用及凭据版本完全一致。预算行锁等待后再次读取请求状态，已恢复终态不得预留或发送。既有唯一 attempt 不自动重试。

旧 synthetic worker、排队拒绝、异常回退及 synthetic transitions 仅处理精确 synthetic 绑定且没有 live 关联的请求；数据库 claim CAS 重复同样检查。共用结果写入接口保留给独立 live 结果事务。共享超时恢复继续终结遗留请求，不调用模型、不退款未知费用、不删除关联/历史。

没有调度器时，新 QUEUED 请求可能被现有 60 秒恢复明确终结；这是基础接口，不是可使用的真实解释入口。生产 `modelCallsAvailable` 仍为 false，公开执行核心仍拒绝发送。

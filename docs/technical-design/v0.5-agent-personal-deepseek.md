## 官方协议核对（2026-10-06）

- [Responses 指南](https://api-docs.deepseek.com/guides/responses_api/)支持 input、instructions、text.format、max_output_tokens、reasoning.effort 和 tool_choice；store 不受支持，响应固定为 false，不能据此证明零保留。
- [Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)说明 Responses 的 reasoning.effort=none 禁用思考。保留 ADR 协议，不转用 Chat Completions，不发送工具或会话字段。
- [模型和价格目录](https://api-docs.deepseek.com/quick_start/pricing/)列示 deepseek-flash → DeepSeek-V4.1-Flash；高峰输入缓存未命中/命中及输出分别为每百万 Token USD 0.30/0.006/1.20。这是查询快照，不是所有者批准的有效价格目录或响应模型标识证据。
- [缓存说明](https://api-docs.deepseek.com/guides/kv_cache/)及 ADR-0012 的未核实处理风险仍适用。实现不能宣称地区、精确保留期限、训练或人工复核已核实。

官方别名不提供客户端可验证的权重版本锁定。启用记录必须同时记录公开映射快照和获准响应 model 标识；首次合成批次可只允许官方请求别名，响应不匹配立即失败。相同响应别名不能证明后端未变更，因此启用有短有效期、启用前人工复核官方目录；变化先关闭出口并重新批准，不声称能自动检测供应商所有隐式变更。

## 增量设置与记录契约

机器表示见 [个人启用记录 Schema](../../contracts/agent-personal-enablement-0.1.0.schema.json)。该 Schema 目前是设计资产，不是已上线 API；不修改 Scanner Schema 或既有 Agent Output 0.1.0。

拟新增 `/api/v1/projects/{projectId}/agent/settings`（GET Viewer，PUT Maintainer，If-Match 乐观锁）与 `/agent/enablements`（POST/撤销仅 Maintainer）。新设置默认 enabled=false、revision=0，无记录引用。PUT 不接受 Secret、URL、价格或任意模型字段；只更新 enabled 和当前有效 enablementId。enablement 必须属于该 Project 和当前部署，撤销不可逆，重新批准生成新版本。读 API 不返回账户真实标识或保密资料。

所有者风险/数据确认、运行检查和具体批次授权分开记录。记录上传不是批准证据：服务端核对当前 actor 是受控部署配置的个人所有者且是当前 Project Maintainer；不可由调用者自报 approver/approvedAt。服务端生成 id、approvedBy、approvedAt，资料链接只保存不抓取，不允许任意 URL 触发网络。

首版运行授权仅支持 SYNTHETIC_ACCEPTANCE：固定用途、合成批次摘要、请求次数及总 microUSD 上限；不得凭这一记录启用日常个人资料。日常用途待独立数据清单和授权实现后扩展，不能隐式把合成批准推广到全部 Project 内容。批次清单锁定 scan/report、所选 Finding、文档版本及其摘要；具体请求必须匹配清单，普通文本自称“合成”不构成证明。

Secret 仅从运行时 Secret 文件读取；文件权限/轮换/出站防火墙检查编号写入记录，不保存内容或路径。记录中的短引用只是核对索引，不自动证明措施已实施；首次运行前所有者须实际检查并另行授权。

## 后端接入顺序与事务

1. 先合入本设计与离线协议校验；没有生产 Bean、HTTP 调用、配置 Key 或迁移。
2. 追加独立 Agent V11：settings、不可变 enablements、撤销事件、批次额度及请求绑定。保留 V9/V10 和主 V1–V8；迁移错误只使 Agent 不可用。验证空库、上一版本升级和历史解释读取。
3. 创建请求核对 Project/资源授权、部署/Project 双开关、启用记录、批次/价格有效期、输入投影。幂等 digest 纳入模型/Prompt/价格目录和启用版本；历史幂等重放返回旧记录，不按新配置重新执行。
4. worker 领取后锁定相同设置/记录/批次状态、再次核对授权和资源版本，事务预留 Project、部署和批次额度并记唯一 attempt。设置关闭/撤销与调用准入按相同锁顺序串行化；已经获准且发出的请求不能被撤回，不承诺开关能撤销在途供应商处理。
5. 出口层仅执行一次 POST；第三次授权及 Schema/业务/引用检查成功后保存最小结果并结算。任何终态重复处理都不能释放/重复结算额度；超时、网络/解析失败及用量未知保留预留，不自动恢复调用。

不能把真实 adapter 标记 syntheticOnly=true 绕过当前防护。新增明确的真实调用策略，保留未批准 adapter 回归；真实路径不能使用合成价格或修改老请求模型绑定。当前 AgentModelPort 无 cachedTokens，后续只在基础设施用量 DTO 增加此信息并维持旧假模型构造兼容；公共结果不暴露供应商原始对象。

## 网络、输入与输出

固定目标 `https://api.deepseek.com/responses`；JDK HTTPS 客户端证书/主机名校验、Redirect.NEVER、显式直连 ProxySelector，不继承环境/系统代理，不接受 endpoint override。DNS 非公网解析拒绝；DNS 检查不能单独防止重绑定，部署出站防火墙仍为必要关卡。测试传输独立注入，不提供生产 loopback/HTTP 开关。

单次总期限最多 30 秒（包含连接、接收和解析），响应最多 64 KiB；超限中止并取消 I/O，关闭流。无逻辑重试，429/5xx/重定向不重发。测试须覆盖取消后线程/连接回收，不能仅证明 future 被取消。异常只保留稳定类别，不携带请求、Authorization 或响应正文到日志/审计。

请求只含 model、instructions、input、text.format、max_output_tokens、reasoning、tool_choice、store；没有 background、metadata、tools、会话、流式或正文日志。input 只接收已有最小 ModelInput，不序列化 Snapshot、Project UUID、请求者、traceId 或凭据。Prompt 版本分别使用 finding-explanation-deepseek-0.1.0 / pr-summary-deepseek-0.1.0，静态指令将输入作为不可信数据，不接受上传内容控制指令。

离线 codec 只处理协议形状：严格 JSON/重复键/未知字段，completed、唯一 assistant message、唯一 output_text、无 annotations/工具/思考/拒绝、非预期模型、非法 usage 均拒绝。供应商可出现的顶层兼容字段需逐个列入 allowlist；未知新增字段失败，不静默适配。接收文本仍需现有 AgentOutputValidator 全量验证，codec 的成功不表示引用可信。

## 用量与费用

批准目录必须版本化且有有效期；按高峰和缓存全未命中预留。首版保守地按 8,000 输入与 1,500 输出最大值预留 4,200 microUSD（USD 0.0042），而非沿用当前 inputBytes + 3,000 的假价格计算。部署/Project/批次限额均在事务内检查，且保持每请求 USD 0.10、Project/部署每 UTC 日 USD 5/20 硬上限。

完整请求 UTF-8 字节数（含 instructions 和 Schema）设保守 6,000 字节准入上限，留 2,000 Token 协议开销预算；字节数不是供应商保证的 Token 上界，发布前须对合成真实批次核对官方实际计数及 Token 估算依据。尚未证明总输入 <=8,000 时不开放真实调用；不得宣称只靠调用后拒绝就能追回已发送 Token。

结算保留实际 input/output/cache-hit Token，检查整型、非负、缓存命中不超过输入、reasoning=0、总数一致以及输入/输出 8,000/1,500 上限。按批准目录高峰单价及缓存命中比例计算、一次向上舍入到 microUSD；这属于保守计价，并非供应商账单金额。官方可能按低峰/赠送余额等计费，实际验收单独核对账单，不混淆。输出/引用失败但用量可信也结算；用量未知或目录不匹配保留预留。

## 验收与后续关卡

# Agent v0.5 — 个人项目设置与不可变启用确认

状态：Issue #43 的后端增量切片；不是完整真实适配器、Web 消费、运行授权或真实验收。没有外部模型调用或费用。

依据：Docs ADR-0012、ADR-0013 与[个人 DeepSeek 设计](v0.5-agent-personal-deepseek.md)。保持官方托管 API（不是部署模型）；[Responses 官方指南](https://api-docs.deepseek.com/guides/responses_api/)于 2026-10-06 再核对，协议不变。

## 范围与契约

- 新增 [OpenAPI 0.1.0](../../openapi/agent-enablement-v1.json) 和[确认输入 Schema 0.2.0](../../contracts/agent-personal-enablement-0.2.0.schema.json)。旧 0.1.0 提案保留为历史设计，不是该 API 的请求格式。
- GET settings / enablement 元数据需要当前 Project Viewer；PUT settings、POST 确认和撤销同时需要当前 Project Maintainer 与受控配置的专用 owner。不能仅凭 Key、admin 角色或自报 approvedBy 操作。写入还复用凭据管理的 local-compose、管理开关、Origin 和环回 HTTP/TLS 约束。
- 默认 enabled=false、revision=0；GET 不写数据库。PUT 必需单一强 ETag If-Match；缺少 428、格式错误 400、旧版本 412。数据库行锁串行化更新与撤销；不是客户端最后写入覆盖。
- enabled 是期望的 Project 开关，不是运行许可。`modelCallsAvailable` 在本切片始终 false；即使所有开关为 true，仍为 LIVE_ADAPTER_NOT_READY。已有请求创建/worker 的 syntheticOnly 防护不变，真实端口未注册。
- 确认与撤销只能追加，ID/Project/部署/actor/时间由后端生成。创建确认不自动打开开关，重复提交生成独立确认（不同于后续模型请求幂等）；撤销同一记录幂等且不可逆。选中记录撤销后设置关闭、引用清空、revision 只增加一次。
- 当前凭据版本来自 agentcredential 的公开只读元数据接口，不提供明文 Key 读取接口。添加/替换/删除 Key 使旧确认失效；当前加密存储无法验证时失败关闭。这里不请求供应商检查 Key 有效性。

## 有界确认与未核实风险

输入在鉴权后最多读取 8 KiB，拒绝未知字段、重复 JSON 键、尾随 JSON、标量类型转换和空输入。撤销仅接受空正文。来源只允许冻结的官方 TERMS、PRIVACY、CACHE、MODEL_PRICE 链接（PROTOCOL 可选），不抓取任何链接。

固定 PERSONAL + SYNTHETIC_ACCEPTANCE、deepseek-flash、`deepseek-v4.1-flash-2026-10-06` 映射快照和 `deepseek-flash-peak-usd-2026-10-06` 高峰价格版本。确认和价格有效期均为未来最多 7 天，确认不能晚于价格失效；来源核对时间只能在过去 7 天以内。响应标识暂仅允许官方请求别名，不声称锁定权重版本。短引用只允许 1–128 位 ASCII 索引，禁止 Key 前缀；不得放真实账户标识、路径、Secret 或个人资料。

八项供应商处理未知风险、七项撤销条件必须全部明确列出且不重复，并显式 riskAccepted=true。此记录只是所有者的风险确认与检查索引，不证明地区、训练、保留期限、缓存隔离已核实，不替代实际检查或具体批次/次数/费用授权。

批次清单、三层事务额度、唯一 attempt、实际 Token/费用结算、网络准入及真实适配器仍需后续切片。不得把本记录推广到日常个人资料，不得为让调用通过把真实端口标为 syntheticOnly。

## 持久化与审计

独立 Agent Flyway V11 仅追加 `agent.project_settings`、`agent.personal_enablements`、`agent.enablement_revocations`。设置用同 Project 的组合外键约束引用；确认/撤销 UPDATE 和 DELETE 由数据库触发器拒绝。有确认历史的 Project 不能删除，通过 Project 的公开删除守卫检查，不跨模块读取其他领域内部实现。保留主 V1–V8 和 Agent V9/V10 不变。

设置/确认/撤销与成功审计同事务；审计失败回滚业务变更。拒绝写入在业务事务回滚后记录稳定 reason/status、actor、Project 和 traceId，不记录输入、账户/来源引用、异常、Key 或文档。审计不可用返回 503，不返回未审计成功。身份认证拒绝发生在全局安全入口；本切片不新增匿名输入日志。

全部新接口响应 no-store（包括匿名 401）。读响应只公开必要版本元数据，不返回来源、账户、检查引用或 Key。错误是稳定通用结构，没有原始异常/正文。

测试覆盖默认关闭、owner 与 Project 双权限、Origin、匿名缓存、严格输入/大小、风险与来源边界、跨 Project、凭据轮换/缺失、过期、If-Match 并发、不可变历史、幂等撤销、成功审计故障回滚和拒绝审计脱敏；仅用合成数据与假凭据元数据。

## 范围与不可变边界

仅所有者本机 OIDC 部署、明确批准的合成批次和 ADR-0014 新上下文费用策略。固定官方 HTTPS Responses、deepseek-flash、原最小投影/Prompt/输出 Schema、6,000 完整字节/1,500 输出、8,000 调用后阈值、316,373 microUSD 预留、350,000/700,000 本地单次/两次上限以及原日额度不变。无 SDK/新依赖、Scanner Schema、工具、余额查询、重试或任意 URL/模型。保留旧假模型及旧策略历史语义。

本 PR 不部署、不读取真实运行凭据、不调用模型，不创建阶段报告。即使合入也仍需 Web、Deploy 候选的 PR/main CI、具体运行绑定与网络检查全部满足后，才可使用已有的两次条件授权；不能重新批准批次规避次数或失败即停。

## 公共入口与装配

- 新增独立 `POST /api/v1/projects/{projectId}/agent/live-requests`，严格 JSON 仅含 `batchId` 与 `templateRequestId`，另有 Idempotency-Key 和可信 Origin。返回现有 AgentRequestView，202/no-store；结果继续用现有 GET 请求接口。不得将旧 synthetic POST 静默切换为真实调用。
- 身份/Project Maintainer/owner/Origin/安全传输、部署配置先于有界解析；客户端不能提供 ModelInput、actor、凭据、URL、模型、价格、用途或强制重试。所有业务输入从已持久化且来源受控的模板复制。
- 独立默认关闭的 `archguard.agent.live.enabled`，同时要求原 Agent 开关、local-compose 与 oidc、有效 Project 设置/确认/来源/批次及当前凭据版本。生产只放行新 context 策略，旧批准不因装配升级。
- 运行配置必须固定 `archguard.agent.live.project-id`、`batch-id`、`network-check-ref` 与 `secret-check-ref`；最后两项须匹配不可变确认。没有通配或自动选最新批次。服务端批准批次后再绑定其确切 ID，不能靠新批次恢复本次已用次数；配置变更须重新核验已有条件授权，不把部署文件当新增费用授权。
- 保留现有公开 core/dispatcher 构造器默认拒绝；受控同模块配置才可创建生产装配。基础设施拥有固定 HTTP 客户端及版本绑定凭据桥接，不向领域层暴露 SDK 或明文 getter。
- 设置的 modelCallsAvailable 仅反映本地受控装配及当前设置有效性，不联网测试 Key、不查询账户；默认仍 false。可用展示不是授权，每次创建、领取及发送仍复核。
- 小容量有界队列、单 worker、可关闭生命周期；关闭后拒绝新任务，取消排队/在途并关闭 HTTP 客户端，验证实际终止而非只设置取消标志。

## 唯一请求与 V16

仅追加 V16：新 context 策略的不可变模板请求槽位，主键 `(project_id,batch_id,template_id)`，外键绑定精确 live_request_link。由 link INSERT 的数据库触发器按不可变 batch 策略填入，不能只做应用 SELECT 后检查。

迁移回填既有新策略关联；若发现同槽多个历史请求则迁移明确失败，不删历史、不选赢家。旧策略不加每模板唯一限制，旧关联和 V1–V15 不改写。新策略每个模板永远只产生一个 request ID：同键重放原请求，换键/并发/失败后/领取但尚无 attempt 时都不能创建替代请求。数据库唯一冲突映射稳定 409，并回滚新请求、关联及成功审计；不能借费用释放恢复次数。

## 一个原始期限与独立清理

worker 开始时创建最多 30 秒的单调预算；领取 CAS/审计、核心准备、资源核验、账本、凭据元数据/消费、最终 HTTP 共用同一个剩余预算，不在领取后给核心续发 30 秒。排队创建后 60 秒的年龄限制独立保留。旧构造/方法保持兼容，但不能成为生产无界回退。

有界领取复用 LiveDatabaseWork 的独立事务与 PostgreSQL LOCAL 超时，锁后、审计后及提交前重新核对原期限。最终发送前还须明确复核可信身份作用域未过期；仅 requester UUID 相同不能证明身份仍有效。已有已发生费用和失败落库仍使用独立有限 cleanup，不因原预算或身份到期抹去费用。

两个公开模块边界补充默认拒绝的有界重载，旧 SAM/方法保持兼容：

- CredentialVersionSource.current(remainingNanos)：同槽可中断/限时元数据锁，LiveAccountingService 的有界预留/发送前检查显式传入原预算，禁止无界 current() 回退或隐式 ThreadLocal 预算。
- AuditRecorder.record(event, remainingNanos)：audit 模块自己的独立有界数据库事务，不依赖 Agent internal 实现；凭据 USE_REQUESTED 在槽锁外使用该方法，审计失败/超期时不进入密钥回调。

共享池获取及 PostgreSQL connect/socket/cancel 必须有有限配置并在生产 profile 验证；SQL statement_timeout 本身不能覆盖连接获取或提交回执。文件/ACL 仅限受控本机常规文件及有界大小，迟到结果不得发送；不能声称任意操作系统 I/O 在第 30 秒可被强杀。原中断状态及新取消必须保留，清理不得恢复发送能力。

可选 `agent-live` profile 只配置个人栈的有限 Hikari 获取/校验（1,000/250 ms）与 PostgreSQL connect/socket/cancel（2/5/1 秒），**不启用** Agent 或真实出口；也可提供等效且被启动准入检查的显式配置。默认 profile 的既有池配置不变。这些参数作用于该个人栈的共享 Platform 池，须保留完整确定性回归及最终 Compose 扫描/门禁核对，不能声称生产负载或新容量 SLO 已通过。

## 网络限制

固定 api.deepseek.com:443、TLS 证书/主机名验证、直接连接、禁止继承代理/重定向/自动重试。固定主机 DNS 预检自身有界，所有解析地址必须公网；拒绝 private、loopback、link-local、ULA、multicast、IPv4-mapped 非公网等。不接受 endpoint/DNS/代理覆盖接口。

DNS 预检不是重绑定防护证明；Deploy 受限出口仍是实际运行前关卡，不能把 Platform 接入任意联网网络即宣称通过。无网络可用性/Key 自动探测。响应最多 64 KiB，剩余期限含接收及解析，失败不返回原文或敏感异常。

地址拒绝依据于 2026-10-16 核对的 [IANA IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry/) 与 [IANA IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry/) 特殊用途登记；使用保守公网子集，不承诺接受所有可路由特殊地址。单个无队列 DNS worker 限制挂起解析数量；系统解析忽略中断时不会产生迟到 HTTP，但关闭可能明确报告未能及时终止，不能将取消标志当作实际回收证明。

## 假 HTTP 验证与合并要求

必须验证真正 Spring 配置及受控 HTTP 路由，而非只手工 new 核心：可信 OIDC/owner/Maintainer → 持久化来源/确认/批次 → 创建/唯一槽/link/领取 → 固定请求/假 HTTP → 独立 usage 结算 → 输出/引用校验 → GET 结果；解释成功且结算后才放行摘要。

正反场景包括：任一开关/配置缺失、错身份/Project/Origin、过期或撤权、Key 换删、批次过期/停止、同键/换键/并发/crash-before-attempt、一次失败后零补发、费用/输出/引用失效、未知费用保留及原 PASS/FAIL/退出码不变。实际等待覆盖领取行锁、凭据元数据锁、USE_REQUESTED 审计锁、池获取、HTTP 正文停顿、取消/关闭后的资源回收。不能降低已有断言。

迁移验证空库、V15→V16、历史/checksum 保留、重复 migrate 零变化、回填冲突显式失败和新旧策略隔离。修改先获得相关红测试，再最小测试、模块架构规则及完整 Maven verify；PR 与合并后 main 的 governance/Maven/container CI 均须成功。

2026-10-16 本地实际记录：共享预算/身份、唯一槽位、有界 metadata/audit、HTTP 入口和配置隔离均先取得失败回归，再通过对应最小检查。完整 Maven Wrapper `verify` 为 **690 项、0 失败、0 错误、3 项既有 Windows 条件跳过**，打包成功；其中真正 Spring/OIDC/加密凭据/账本/校验链路的 **11 项**全部通过。假 HTTP 固定 usage 只用于算法断言，不代表提供方用量、模型质量或真实账单；没有模型/账户请求、运行 Secret 读取或部署变更。测试中的匿名身份和 worker 暂停点按实际框架/锁语义设置，保留 401、零请求、串行、两次上限及门禁逐字不变断言。

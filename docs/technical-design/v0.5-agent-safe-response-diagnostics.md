# Agent v0.5 — 脱敏响应拒绝诊断

范围：#43 的离线排查增量。所有者批准重新打开 Issue，并仅增加脱敏失败分类及离线回归；不批准新真实请求、费用、Key/账户探测或部署。上次一次真实解释返回 `OUTPUT_INVALID`、无可信 usage、费用 `UNKNOWN`；原始响应没有保留，不能据此断言具体字段、模型质量或 Key 有效性。本增量不能追溯恢复已丢弃响应，也不是实际模型故障已经修复的证据。

## 选择与边界

采用现有 Java/SLF4J/Logstash 日志，无新依赖。固定枚举在基础设施包内携带拒绝原因，异常仍无 cause/原文；在同步 `DeepSeekLiveResponseClient` 边界仅记录一条结构化诊断，复用 worker 已隔离的 `traceId`。HTTP 异步订阅器只携带固定原因，不在可能缺少请求 MDC 的回调线程输出日志。不把诊断写入可变 MDC。

诊断默认仅含固定 event、stage、reason；不含请求/响应正文、JSON 路径或未知字段名、Content-Type 实际值、模型/响应 ID、用量值、凭据、文档/源码、异常对象或解析器消息。阶段覆盖 HTTP 响应边界、JSON/封装、用量与业务文本；未知异常使用固定 fallback，不能把 exception.getMessage() 当诊断。业务领域完整 Schema/引用校验仍由原执行核心负责，本增量不宣称对其每个子步骤单独分类。

## 2026-10-23：获批的根结构诊断细分

所有者另行批准仅离线区分根结构和未知字段，并增加有界数量，不批准部署或新调用。根节点缺失、JSON null、数组及标量固定分类为 `RESPONSE_ENVELOPE / ENVELOPE_NOT_OBJECT`，日志仍恰好三个固定键；根对象含任一未知字段固定分类为 `RESPONSE_ENVELOPE / ENVELOPE_UNKNOWN_FIELDS`，仅此事件增加一个整型 `unknownFieldCount`。

只统计根对象不在既有白名单中的名称数量，不保留名称、值、JSON 路径、根对象或字段摘要。数量范围为 `1..32`；`32` 表示至少 32 个，不声称是精确总数。32 是本地实现的诊断饱和上限，不是提供方协议限制。达到上限即可停止计数，但任何数量的未知字段仍拒绝；完整 JSON 的重复键、尾随内容与解析错误仍先于字段计数拒绝。嵌套未知字段保持原用量/输出分类，不混入该数量。

其他拒绝事件不增加数量键；成功无拒绝日志。数量保存在内部异常的整数载荷中，不进入公开错误、业务结果、用量或审计，不加入 MDC。异常和字节清理继续不携带提供方正文/cause。此前 `ENVELOPE_FIELDS` 日志保留原含义（根非对象或未知字段），不能用新分类反推旧请求具体原因；原始响应未保留，离线合成案例也不能复现或证明真实失败根因。

保持公开 `OUTPUT_INVALID`/`MODEL_UNAVAILABLE`/`MODEL_TIMEOUT`、API/Schema、请求字段、模型单元素白名单、6000 字节/1500 Token/64 KiB 边界和无重试不变。未知用量仍保留预留、停批；已经可信的用量在业务文本被拒绝时仍返回执行核心独立结算，不能因诊断把已知费用改为 UNKNOWN。响应字节清理和异常脱敏不得回退，不新增原文留存或堆内完全清除承诺。

## 验证与兼容

使用手写合成 envelope 和本机假 HTTP；分别覆盖 Content-Type/空体/超大体、坏 JSON/重复字段/尾随 JSON、封装字段/状态/模型、用量字段/数值/缓存/推理、业务结构/业务 JSON/当前凭据回显。断言实际客户端单次交换、公开结果与费用语义保持、每次恰好一条诊断，日志 rendered message/arguments/key-value/MDC/ThrowableProxy 均不携带私有哨兵，持久 trace 正确且作用域恢复。成功不得产生拒绝日志。

根结构增量还覆盖各类标量/null/数组、未知数量 1/2/31/32/33/1000 的饱和、批准元数据和嵌套内容不改变根计数、解析错误优先、恶意名称中的合成 Key/CRLF/Unicode 不泄漏，以及同一客户端连续失败/成功不残留数量。其余事件继续精确断言三个键，未知根字段事件精确断言四个键，不改成宽松子集断言。

先观察新增测试在旧实现失败，再实现并运行最小测试、完整 Maven verify 和代码/安全评审。无数据库迁移、契约快照或 Web/Deploy 改动；活动 8081 栈仍是旧固定候选、所有出口关闭，不在本任务升级。应用回退即可移除此诊断增量；历史请求、UNKNOWN 预留、审计、迁移和凭据卷保留，不改写记录。本地假 HTTP 通过不能替代单独获批的后续真实验收，也不关闭 #43/4H/阶段 4。

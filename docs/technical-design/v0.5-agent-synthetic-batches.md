# Agent v0.5 — 受控合成来源与批次管理 API

状态：Issue #43 的后续后端切片。只管理来源绑定与批次元数据，不发送请求、装配真实模型、启用 Web 或替用户批准费用。依据 ADR-0012/0013 与[账本设计](v0.5-agent-live-accounting.md)，不改变供应商、官方 Responses 协议、外发字段、Scanner Schema 或 Agent Output 0.1.0。无新增依赖。

## HTTP 边界

[API 0.1.0](../../openapi/agent-batches-v1.json)包含四个入口：POST `.../agent/batches/preview`、POST `.../agent/batches`、GET `.../agent/batches/{batchId}`、POST `.../agent/batches/{batchId}/revoke`。预览和写入必须先验证配置的 owner、Project Maintainer、Origin 和传输，再解析正文；读取仍要求 Project Viewer。预览输入只有 1–20 个不同模板 UUID，返回版本、服务器 manifest 摘要和数量，不返回原始输入或来源证明。

批准复用 Batch Input 0.1.0 的八个字段，不接受自报 actor/时间、Key、内容或来源上传。严格 JSON 最大 8 KiB，拒绝重复/未知字段、尾随对象和类型强制转换。撤销只接受空正文，追加事件且幂等。批准要求显式 callsApproved=true、有效个人确认及当前凭据版本、已核验清单，期限不得超过确认、价格目录及来源证明；它不创建 Agent 请求或 attempt，也不是网络授权。没有 reserve、settle、请求 digest 或发送 HTTP 入口。

所有响应（含安全过滤器的 401、拒绝和解析错误）为 `Cache-Control: no-store`。稳定错误码配 traceId，不返回输入、路径或异常详情。边界鉴权/解析失败另审计 `agent.batch.http_rejected`；批准/撤销应用层失败沿用业务回滚后的独立审计，不重复记录。审计失败关闭操作。

## 操作员来源证明

唯一生产 `SyntheticBatchInventory` 实现默认拒绝。独立 `ARCHGUARD_AGENT_SYNTHETIC_INVENTORY_ENABLED=false` 和固定 `ARCHGUARD_AGENT_SYNTHETIC_INVENTORY_FILE` 仅在 local-compose 有效；不接受 Web 上传、请求指定路径、网络 URL 或 Git 克隆。启用和部署文件仍属于后续 Deploy 切片，本轮不填写真实批准记录。

[清单 Schema 0.1.0](../../contracts/agent-synthetic-inventory-0.1.0.schema.json)固定部署 UUID，1–20 项绑定 inventory UUID、Project UUID、精确 manifest SHA、CONTROLLED_SYNTHETIC_FIXTURES、案例版本/制品摘要、非敏感 reviewRef、审核和失效时间；全部项都需有效且 inventory ID 不重复。最长 24 小时，未来审核、过期、未知字段、重复 JSON 键、非规范 UUID、密钥样式引用均拒绝。文件最多 32 KiB，有界深度和字符串；配置/读取/解析失败只关闭 Agent 准入，不影响核心启动。

文件与父目录须为绝对规范真实路径，拒绝符号链接和外部写权限（POSIX group/other 或 Windows 非 owner/SYSTEM 的写授权），可允许只读授权供应用读取。Deploy 须保证所有祖先目录和挂载由可信操作员控制、其他用户无重命名能力，使用只读挂载；本校验不防御已控制同一 OS 账号或管理员的攻击者，也不是整条路径的无竞态文件锁。操作员核验内容确为合成后生成记录；摘要只证明内容一致性，**不能自行证明内容是合成或构成用户费用授权**。每次批准和新预留重新读取，不缓存成功结果。

独立 V13 只追加 nullable `inventory_proof`，批准快照保存原始文件 SHA、案例/审核版本和时间。即使仅更改文件空白，旧批次的新 attempt 也会被拒绝，必须重新批准。撤回或过期同样失效；全部预算锁获取后再次核对权限、证明、有效期和凭据，跨 UTC 日等待直接拒绝，不能用旧日额度创建新日 attempt。V12 旧批次保留 null 证明，可读取/撤销，不能新预留；已经发生的费用仍按原账本结算。数据库原不可变触发器继续保护新增字段，不回填虚构证明或改写旧迁移。

# Agent v0.5 — 版本绑定的加密凭据消费基础

范围：承接 ADR-0013 和默认关闭的真实执行核心，提供内部可信回调消费当前加密 Key，并修正调用前检查的锁序。Platform 仍为 0.4.0；不改变 Scanner、公开 REST/OpenAPI、输出契约、密文格式、迁移或依赖。**不是“保存 Key 后即可真实解释”**：不注册真实客户端/worker、请求创建/调度入口或允许外发的策略，不修改运行中的 Compose，也不进行账户或模型请求。

## 模块边界与固定槽位

`CredentialUseSource.consume(expectedVersion, finalOperation)` 是可信内部模块边界，不是明文 getter。`StoredCredentialUseSource` 委托凭据管理服务已经缓存的同一个存储实例，不能新建第二个锁域。仅 configured owner、local-compose 和已开启凭据管理可使用；Project 授权、批准和费用由调用者另外验证。元数据接口和浏览器响应仍只提供状态、版本和时间，不返回 Key、指纹或文件路径。

存储在同一进程槽位锁内认证密文、严格匹配期望版本，再执行一次最终回调。[有界等待补充](v0.5-agent-bounded-credential-wait.md)将原 monitor 改为共享可中断锁，并让真实核心只使用有界消费重载。替换/删除先完成则旧版本不能开始回调；回调已开始时替换/删除等待它释放锁，不能撤回已经发出的网络请求。删除没有旧版本或环境 Key 回退。错误主密钥、AAD、篡改、缺失/过大封装和不安全路径/权限均失败，不调用回调、不重置密文。

可信回调只能完成最终发送，不得缓存/日志记录 Key、进入其他模块、调度后续异步 Key 使用或调用凭据操作。存储显式拒绝同线程的重入消费、状态、替换和删除；服务层的线程作用域还在 actor 查询和审计之前拒绝重入。其他线程仍按同一个锁串行。标志与主密钥/明文 byte[] 在 finally 清理；JVM String、HTTP/加密提供者内部拷贝不保证物理擦除。此接口不是对不可信 Java 代码的沙箱，不支持多进程共享存储。

## 调用前检查与锁序

执行核心的 `CredentialUse` 分离成 `expectedVersion + preflight + finalSend`。新增的 `VersionBoundCredentialUse` 不注册 Bean，仅供后续显式装配：先在锁外运行 preflight，再使用已批准版本的 Key。执行核心强制 preflight 完成且至多一次，拒绝跳过或吞掉失败后发送，以及无发送回调的伪造成功。

preflight 在锁外重新核对批次/设置/批准/当前凭据元数据、资源权限、出口准入和 RUNNING 状态；获取凭据锁后只进行单调期限检查、一次发送 CAS、传输调用及观察延迟。不能在凭据锁内访问设置/费用/请求数据库、公共领域 API 或 AuditRecorder，避免设置 → 凭据与凭据 → 设置反向等待。桥接及核心仅允许本次 use 内同一调用线程的同步回调；保存回调迟到执行或换线程均不能开始发送。锁等待消耗同一 30 秒预算，超时后即使得到 Key 也不开始发送；没有重置时钟或自动重试。

只有凭据替换/删除与消费在本进程内具有上述线性化语义；其他授权/开关检查不宣称与最终网络动作原子提交。并发撤权仍须保存结果前重新核验，可能已经产生的费用不能撤销。同步文件/数据库等待的硬取消、生产调度、可信身份/trace 作用域和遗留恢复仍未完成，因此没有开放生产出口。

## 审计、失败与费用

owner 和配置检查后，先写 `AGENT_CREDENTIAL_USE_REQUESTED` 意图事件，再获取锁/解密。仅含 actor、traceId、provider 和期望版本；审计失败零消费。它不证明 HTTP 已发送或费用已产生。最终回调不补写数据库审计；发送结果由已有独立账本和结果审计在锁释放后记录，避免成功 usage 被一次事后凭据审计故障丢弃。

桥接层捕获最终发送中的异常：只保留既有安全 CallFailure 码；没有回复时的存储/未知异常转换为无 cause 的 MODEL_UNAVAILABLE，owner 拒绝作为权限失败。重复回调最多发送一次并失败关闭。若已收到回复，后续来源异常或重复回调不能丢掉合法费用证据：清空业务文本并标记 OUTPUT_INVALID，保留 usage/安全追溯字段。核心独立保存实际传输回复，不信任消费接口替换回复；接口迟报失败或违约同样不能使已知费用变成 UNKNOWN。仍先验证/独立结算合法 usage，再拒绝业务内容、引用或结果。无可信 usage 的失败仍保留预留，不自动重试。

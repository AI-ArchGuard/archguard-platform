# Agent v0.5 — 个人只写凭据管理

依据：Docs [ADR-0013](https://github.com/AI-ArchGuard/archguard-docs/blob/main/adr/0013-personal-write-only-credential-management.md)已合并为 `fce238b` 且 main CI 成功。仅替代凭据输入渠道，不批准真实调用。新增[API 0.1.0](../../openapi/agent-credentials-v1.json)，Platform 仍 0.4.0；无新依赖、迁移或 Scanner Schema 变更。

## 范围与请求

`agentcredential` 为模块化单体中的独立小模块，仅依赖 identity/audit/common 公开接口。固定部署槽位，配置的 owner UUID 专用；Project Maintainer 或自报身份头不能授权。只返回 configured、credentialVersion、updatedAt。没有读取/测试 Key 的接口、模型客户端或 AgentModelPort；真实出口未注册，syntheticOnly 防护不变。

独立管理开关默认关闭，仅 local-compose profile 可开启；Origin 限 localhost/127.0.0.1/[::1]，PUT/DELETE 要求精确匹配，GET 若携带也验证。HTTPS 不信任任意 Forwarded 头；本机 HTTP 要显式 opt-in，并依靠 Deploy 把 Web 绑定环回、Platform 仅监听内部网络。Origin 不是业务授权替代，公网/多人部署不支持。

授权后有界读取最多 513 字节，超过 512 拒绝；明确 WriteRequest DTO，拒绝重复/未知字段、尾随对象和非法 Key。输入为 16–256 个 ASCII 字母/数字/下划线/连字符，不证明提供方有效性。错误无 cause/原文，DTO toString 脱敏；全部响应 no-store，包括 401。

## 加密与文件

AES-256-GCM、随机 96 位 nonce、128 位 tag；AAD 绑定提供方、personal、格式与稳定 deployment UUID。密文内包含随机版本、时间、Key；二进制封装最多 512 字节。主密钥必须恰好 32 个原始随机字节，从独立 Secret 文件读取，不接受明文 Key 环境变量。

操作员预建专用绝对目录及**目录外**主密钥文件；后端不生成/修复配置或修改操作员 ACL。路径规范化与 real path 相等，目录/常规文件 NOFOLLOW；POSIX 禁止 group/other 权限（目录 700、文件 600/400），Windows ACL 仅 owner 和 SYSTEM 可 allow。父目录/卷也须由所有者控制；不是对已攻陷相同 OS 用户的保护。默认全员可读的容器 Secret 不满足要求，需正确属主/模式。

先认证现有密文，错误主密钥/篡改不覆盖或删除。临时文件创建即私有，写密文并 force，再 ATOMIC_MOVE/REPLACE_EXISTING；不支持则失败，不回退非原子替换。单 Bean synchronized 串行操作，首版仅单进程，不能共享给多实例。主密钥/明文 byte[] 用后清零，但 JVM String/提供者内部拷贝不保证擦除。删除不保证磁盘物理擦除/快照，也不撤销账户 Key。

## 审计与失败

复用 AuditRecorder，部署事件 projectId=null，只记 actor/action/result/traceId/provider 与可用时的版本。先落写/删 REQUESTED 意图，审计失败不开始变更，再记录结果；授权拒绝、畸形 JSON、存储失败不保存原文/路径/密文。

文件与数据库无共享事务：结果审计失败可能在变更后返回 503，须手工刷新状态，不自动重试。配置错误只使凭据 API 不可用，不阻止扫描启动。删除不回退环境/旧文件 Key，历史结果/审计保留。后续真实端口须绑定并核对 credentialVersion、撤销旧版本启用批准；本次未装配端口，不能宣称“添加后已接通解释”。

## 配置、验证与回滚

运行时配置：`ARCHGUARD_CREDENTIAL_MANAGEMENT_ENABLED`、`ARCHGUARD_CREDENTIAL_OWNER_ID`、`ARCHGUARD_CREDENTIAL_DEPLOYMENT_ID`、`ARCHGUARD_CREDENTIAL_UI_ORIGIN`、`ARCHGUARD_CREDENTIAL_ALLOW_LOOPBACK_HTTP`、`ARCHGUARD_CREDENTIAL_DIRECTORY`、`ARCHGUARD_CREDENTIAL_MASTER_FILE`。不提供 API Key 环境变量或余额/有效性查询。主密钥不贴聊天、不进 Git；与密文分开托管，不能一起公开备份。

合成测试覆盖重启、篡改/错误主密钥、部署 AAD、替换/删除/并发、有界输入、权限/Origin、脱敏、审计失败前零变更及请求表零新增。最小测试 → 完整 verify → PR/main CI 后，Web 消费固定快照，Deploy 再交付挂载和环回绑定。回滚先关闭 UI/管理/模型开关再退应用，保留密文、主密钥和历史记录。#43、4H 和阶段仍待真实授权、账本、出口、验收与发布。
